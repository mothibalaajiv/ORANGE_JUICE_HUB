STEP 1: CREATE ADMIN USER
================================================================================

    venv\Scripts\activate

STEP 3: HOW TO APPROVE BRANDS & SUPERMARKETS
================================================================================

1. Start both servers:
   
   Terminal 1 - Backend:
   cd backend
   venv\Scripts\activate
   python run.py
   
   Terminal 2 - Frontend:
   cd frontend
   npm start

2. Login as admin:
   
   Go to: http://localhost:3000/login
   Enter email: admin@tangytown.com
   Enter password: Admin@123
   Click "Login"

3. Go to Approvals page:
   
   From admin dashboard, click "Pending Approvals"
   Or go directly to: http://localhost:3000/admin/approvals

4. Approve pending items:
   
   - Click ORANGE "Approve" button next to brands
   - Click ORANGE "Approve" button next to products
   - Click ORANGE "Approve" button next to supermarkets

================================================================================
APPROVAL WORKFLOW
================================================================================

BRANDS:
1. User signs up as "Brand" → Status: Pending
2. Admin approves brand → Status: Approved ✅
3. Brand can now add products
4. Admin approves products → Products visible to customers ✅

SUPERMARKETS:
1. User signs up as "Supermarket" → Status: Pending
2. Admin approves supermarket → Status: Approved ✅
3. Supermarket can now add inventory
4. Products become available for orders ✅

================================================================================
TROUBLESHOOTING
================================================================================

Q: Admin already exists?
A: Just use the existing credentials above!

Q: Can't login?
A: 1. Check MongoDB is connected (python test_mongodb.py)
   2. Check if admin exists in MongoDB Atlas
   3. Try creating admin again

Q: Approval button not working?
A: 1. Refresh the page
   2. Check backend console for errors
   3. Ensure you're logged in as admin
